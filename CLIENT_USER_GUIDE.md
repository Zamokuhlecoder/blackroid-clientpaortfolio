# Portfolio Client Portal - User Guide

Welcome to your **Blackroid Portfolio Client Portal**! This is where you can track the progress of your projects in real-time.

## 🚀 Getting Started

### Sign Up

1. Visit the sign-up page: `/auth/signup`
2. Enter your:
   - Full name
   - Email address
   - Password (minimum 6 characters)
3. Click "Sign Up"
4. You'll be automatically logged in and taken to your dashboard

### Sign In

If you already have an account:

1. Visit the sign-in page: `/auth/signin`
2. Enter your email and password
3. Click "Sign In"
4. You'll see your project dashboard

## 📊 Dashboard

Your dashboard shows all projects created for you:

### Project Card Information

Each project card displays:

- **Project Title** - What the project is about
- **Status Badge** - Current status:
  - 🔵 **Planning** - Project is being planned
  - 🟡 **In Progress** - Work is actively happening
  - 🟢 **Completed** - Project is finished
- **Description** - Short summary of the project
- **Progress Bar** - Visual representation of completion (0-100%)
- **Timeline Info**:
  - Start date when work began
  - Target date for completion

### View Project Details

Click any project card to see more detailed information:

- Detailed project description
- Timeline (start → target → completion dates)
- Deliverables and milestones
- Project notes and updates
- Images and media uploads

## ✨ Features

### Real-Time Updates

Your dashboard updates in real-time:
- When we update project status

### Project Status Tracking

Track your projects through every stage:
1. **Planning** - Initial concept and requirements
2. **In Progress** - Active development/design
3. **Completed** - Project delivery

### Progress Percentage

See at a glance how much of your project is complete (0-100%)

### Timeline Management

View important dates:
- When work started
- When completion is expected
- Actual completion date (when finished)

## ❓ Frequently Asked Questions

**Q: Can I see other clients' projects?**
A: No, you only see your own projects for privacy and security.

**Q: How often is the dashboard updated?**
A: Updates appear immediately when our team changes project status or progress.

**Q: Can I upload files?**
A: Yes! Click on a project to see the upload option for deliverables and images.

**Q: What if I forgot my password?**
A: Use the "Forgot Password" link on the sign-in page (coming soon).

**Q: Can I message the team?**
A: Project notes include team communications (this feature will be enhanced).
